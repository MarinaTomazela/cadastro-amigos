# Cadastro de Amigos

Projeto acadêmico desenvolvido para a disciplina de Programação Web II.

## Funcionalidades

- Login demonstrativo
- Cadastro de amigos
- Consulta dos registros
- Busca por nome, e-mail ou cidade
- Alteração de cadastro
- Exclusão individual
- Exclusão de todos os registros
- Exportação dos dados em JSON
- Tema claro e escuro
- Layout responsivo

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- SessionStorage

## Login

Use os seguintes dados:

- Usuário: `admin`
- Senha: `1234`

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Entre usando o usuário e a senha de demonstração.

## Publicação no GitHub Pages

1. Crie um repositório chamado `cadastro-amigos`.
2. Adicione os arquivos `index.html` e `README.md`.
3. Abra `Settings`.
4. Entre na opção `Pages`.
5. Em `Build and deployment`, selecione `Deploy from a branch`.
6. Escolha a branch `main` e a pasta `/root`.
7. Salve e aguarde a publicação.

## Observação

Esta é uma versão front-end para demonstração acadêmica. Os dados são
armazenados no navegador do usuário e o login não possui segurança de servidor.

Para uma aplicação real, seria necessário utilizar PHP, banco de dados e
autenticação no back-end.
